# Lark 订阅额度预警

管理端进入 **系统设置 → 网关服务 → Lark 订阅额度预警**。这是全局管理员配置；后台任务独立运行，页面关闭后仍会评估额度。

1. 在国际 Lark 群添加自定义机器人，复制 `https://open.larksuite.com/open-apis/bot/v2/hook/...` Webhook。机器人开启签名校验时，同时填写签名密钥。关键词限制应允许 `Sub2API`，IP 限制应允许服务端实际出口。
2. 填写使用率阈值，默认 `95, 100`，选择 5 小时、7 天窗口，启用并点击本卡片的 **保存预警配置**。保存本身不发送测试消息，但启用后后台可立即对已达阈值的有效样本发送自动预警。
3. 如需检查机器人，在保存后点击 **发送测试通知**。该按钮会实际发出一条标明为测试的消息；关闭自动预警时也可手动测试。连续测试间隔至少 10 秒。

默认关闭。未配置、关闭或显式清空 Webhook 时不发送自动通知。秘密输入留空会保留原值；清空必须勾选对应选项。读取接口只返回“已配置”标记。阈值可填 1–10 个大于 0、不超过 100 的百分比，自动排序去重。

Webhook 和签名密钥使用既有 SecretEncryptor 加密存入 settings。服务端必须预先配置稳定的 `TOTP_ENCRYPTION_KEY`；多实例使用同一密钥，备份时保留它。缺少持久密钥时拒绝保存新秘密。不要在改镜像时重新生成该密钥，否则已有 TOTP 和机器人秘密将无法解密。

## 数据与告警规则

- 监控 active 的非影子 OpenAI OAuth、Anthropic OAuth / SetupToken 账号；跳过 API Key、其他平台和合成 UI 测试账号。通知中的邮箱来自上游账号 credentials/extra 中的 email。
- 只使用真实 5h / 7d 的使用率和未来重置时间；各窗口单独记录采样时间，超过 5 分钟、缺失、无效或只有一般 429 的数据跳过。不会把本地用户余额、金额配额或限流状态估算成订阅 100%。
- 成功请求更新额度快照后，非阻塞投递账号 ID；事件只读快照。后台每分钟补扫，每个平台每轮最多一页 100 个账号，队列满时保留扫描位置并轮换平台。账号池较大时，补扫一轮需要多分钟。
- 没有新鲜快照时，后台复用已有额度查询与缓存；SetupToken 无主动查询能力，需等待真实请求采样。后台不发合成模型探测、不自动清除账号错误、不消费重置卡。OpenAI 额度接口还会读取重置卡详情，属于既有只读查询行为。
- 每个账号、窗口独立记录周期及最高成功档位。例如 `94 → 95 → 99 → 100 → 100` 只发送两条；第一次看到 100 或从 94 跳到 100，只发最高档。重置时间 5 分钟以内的漂移不另开周期；原重置时间到期，或重置明显变化且使用率下降时，允许新周期提醒。
- 去重和每档重试次数保存在既有 PostgreSQL `idempotency_records`，使用独立 scope 和数据库 lease，重启与多实例共享状态。每档每周期最多尝试 3 次，失败间隔至少一分钟；机器人返回非零业务 code 也算失败。失败不提高成功档位。修改机器人不会自动重发已成功的周期档位。
- Lark 发送超时 5 秒，不跟随重定向；4 个 worker、有界队列和退出取消。日志只记录账号 ID、窗口、阈值和脱敏失败，不记录 Webhook、签名密钥、邮箱或消息正文。消息包括名称、邮箱、平台、分组、窗口、已用/剩余百分比及北京时间重置时间。

## 接口与限制

沿用管理员认证及权限：`GET/PUT /api/v1/admin/settings/lark-quota-alerts`，`POST /api/v1/admin/settings/lark-quota-alerts/test`。受限管理密钥默认不能访问；完整管理权限可以访问。普通用户没有这些接口权限。

HTTP 2xx 且 Lark 业务 `code=0` 表示机器人接口受理，不等同于最终群消息可见。远端已受理而本地超时、进程在发送后落库前退出，或落库失败等不确定情况下可能重复；有限重试也可能最终未投递。清空/关闭会阻止后续发送，已经开始的网络请求无法撤回。

本功能在 fork 的 `feature/lark-quota-alerts` 开发；同一个 OpenSpec 变更由 ai-gateway 的 `add-lark-subscription-quota-alerts` 管理。ai-gateway 从锁定官方归档叠加 `integration.patch` 和 `overlay` 重建，维护镜像为 `sub2api-otel:0.2.24-lark.1`，包含此前遥测与安全补丁。配置和状态复用已有数据库，无需新增数据库迁移。

本地测试使用合成数据和 mock HTTP。真实机器人配置、消息投递、现有实例升级及生产验收需另行执行。
